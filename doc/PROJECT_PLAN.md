# 开发计划

> 总工期 6 周：4 周开发 + 2 周联调

---

## W1 — 基础搭建 + supersplat 集成

- 项目脚手架搭建（Vite + React + TypeScript + Electron 骨架）

- 3D 场景编辑器核心功能（位移/旋转/缩放 Gizmo）

- 模型加载与管理
- MQTT 实时监控（遥测数据展示、姿态同步）

## W4 — 勘察任务

- 配置菜单（增删改查）

## W5 — 联调：基础配置 + 空间编辑
