## 二、数据模型层级关系

设备点位导入的数据模型采用五级树形结构：

`
厂站 (Station)
 └── 电压区域 (Voltage)
      └── 间隔 (Bay)
           └── 主设备 (MainDevice)
                └── 部件 (Component)
                     └── 点位 (DevicePoint)
`

### 各实体核心字段

**DeviceVoltage（电压区域）**
- voltName / voltCode：电压名称/编码
- stationId / stationName / stationCode：所属厂站
- alarmLevel：告警等级（0:正常 1:预警 2:一般 3:严重 4:危急）

**DeviceBay（间隔）**
- bayType / bayName / bayCode：间隔类型/名称/编码
- voltId / voltName / voltCode：所属电压区域
- stationId / stationName / stationCode：所属厂站

**DeviceMain（主设备）**
- mainDeviceType / mainDeviceName / mainDeviceCode：主设备类型/名称/编码
- phaseType：相位类型（0:主体 1:A相 2:B相 3:C相）
- threePhaseFlag：是否三相设备
- entityId：实物ID
- deviceModel / manufacturer / productionCode：型号/厂家/出厂编号
- productionDate / commissioningDate：生产/投运日期
- bayId / voltId：所属间隔/电压区域

**DeviceComponent（部件）**
- componentName / componentType / componentCode：部件名称/类型/编码
- mainDeviceId / mainDeviceName / mainDeviceCode：所属主设备
- phaseType：相位类型
- bayId / voltId / stationId：所属间隔/电压/厂站

**DevicePoint（点位）**
- pointName / pointCode：点位名称/编码
- recognitionTypeList：识别类型（逗号分隔）
- saveTypeList：采集类型
- meterType：表计类型
- positionStateType：位置状态类型
- defectRecType：缺陷识别类型
- pointTagsCodeList：点位标签编码
- defectJudgeType：缺陷判读标识
- importantLevel：重要等级（1:Ⅰ类 2:Ⅱ类 3:Ⅲ类）
- demarcateState：标定状态（0:未标定 1:已标定）
- inspectionSubType：巡检子类型
- robotId / robotName：所属机器人
- componentId / mainDeviceId / bayId / voltId / stationId：所属各层级
- mapCode：巡检点所在地图

## 三、导入方式总览

系统支持三种导入方式：

| 导入方式 | 接口路径 | 输入格式 | 适用场景 |
|----------|----------|----------|----------|
| Excel 导入 | POST /devicePoint/importDeviceExcel | .xlsx 模板 | 批量导入本地点位 |
| XML 导入 | POST /devicePoint/importDevicePointByXML | .xml 文件 | 从其他系统迁移点位 |
| JSON 导入 | POST /devicePoint/insertFacNodeByJson | .json 文件 | 创建场站完整节点树并下发 |

## 四、Excel 导入流程

**入口**: DevicePointController.importDeviceExcel() -> DevicePointServiceImpl.importDeviceExcel()

**流程**:
1. 文件校验 — 检查 MultipartFile 格式合法性
2. 读取 Excel — Hutool ExcelUtil.readBySax() 流式读取，解析标题行（第2行）和数据行
3. 表头校验 — LocalPointExcelEnum.checkTitleColumn() 验证模板列标题
4. 参数校验 — 验证 stationId（厂站）和 robotId（机器人）数据库是否存在
5. 数据校验 — checkPointExcelData() 逐行校验点位数据
6. 错误标注 — 如有错误，markExcelErrorInfo() 在原 Excel 中标注错误并返回
7. 保存数据 — saveLocalPointExcelData() 将校验通过的数据保存入库

**配套功能**:
- 导出模板: GET /devicePoint/downLoadExcelTemplate — 下载标准模板
- 批量编辑: POST /devicePoint/batchEdit — 支持 Excel 批量更新点位名称

---

## 五、XML 导入流程

**入口**: DevicePointController.importDevicePointByXML() -> DevicePointServiceImpl.importDevicePointByXML()

**流程**:
1. 解析 XML — XmlUtils.toBean() 反序列化为 DevicePointXmlBO
2. 提取厂站 — 按 stationCode 分组设备点位于列表
3. 自动创建厂站 — 数据库中不存在的厂站自动创建（名称如 "xml导入厂站N"）
4. 参数校验 — checkXmlParam() 验证数据完整性
5. 转换并保存 — buildExcelImportParam() 将 XML 数据转为 Excel 导入参数，复用 saveLocalPointExcelData()
6. 刷新缓存 — taskService.asyncRefreshCache() 异步刷新任务缓存

---

## 六、JSON 导入流程

**入口**: DevicePointController.insertFacNodeByJson() -> DevicePointServiceImpl.insertFacNodeByJson()

**流程**:
1. 文件大小校验 — 限制不超过 10MB
2. 读取 JSON — readJsonFile() 解析为 List<Map>
3. 合法性校验 — checkIsLegal() 验证数据结构
4. 处理设施 — devicePointService.processFacility() 处理设施和机器人绑定
5. WebSocket 通知 — 发送 IMPORT_JSON 进度消息
6. 机器人校验 — 检查关联机器人存在性
7. 点位下发 — batchDistributePoint() 逐厂站批量下发
8. 标定同步 — 间隔 5 秒后 batchSyncCalibratePoint() 获取标定数据
9. 刷新缓存 — 清除 Redis 中机器人任务缓存
10. 模型同步 — modelSync() 同步到图像系统
11. 标准任务创建 — quickTaskCreate() 后台创建标准巡检任务

## 八、技术栈

- **ORM**: MyBatis-Plus（ActiveRecord 模式）
- **Excel**: Hutool ExcelUtil + Alibaba EasyExcel + MyExcel
- **XML**: 自定义 XmlUtils
- **JSON**: Alibaba FastJSON
- **文件上传**: Spring MultipartFile
- **远程调用**: Spring Cloud Feign
- **权限**: Spring Security @PreAuthorize
- **日志**: @OperationEventLog 操作事件注解
- **通知**: WebSocket（导入进度）
- **缓存**: Redis（任务缓存刷新）
- **事务**: @Transactional
